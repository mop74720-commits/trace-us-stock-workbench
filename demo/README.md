# TRACE · 美股工作台 Demo

浅色顶部导航、行情图、自选股和新闻列表。真实行情通过本地 Python 服务读取 Yahoo Finance；无需 API Key 或付费订阅。也可以手动切换到固定模拟数据。

## 打开

在项目根目录安装时区数据并启动服务（Python 3.9+）：

```powershell
python -m pip install -r requirements.txt
python demo/server.py --port 8765
```

然后访问 http://127.0.0.1:8765 。请保持地址和端口不变，以继续读取原有浏览器记录。旧的 `python -m http.server` 只能提供静态文件，不能提供真实数据 API。直接打开 HTML 时可手动选择模拟模式。

## 已实现

- 总览：SPY／QQQ／IWM 行情摘要、价格图、自选股、相关新闻、待处理计划。
- 自选股与行情联动，1M／3M 切换；价格图支持鼠标和左右方向键查看数据。
- 真实模式支持 SPY、QQQ、IWM、NVDA、MSFT、AMD、AAPL、TSLA；报价、涨跌幅及价格图来自同一 Yahoo chart 响应。
- 昨收取报价日期之前的最近交易日收盘；不会把三个月区间的 `chartPreviousClose` 误当昨收。当日日线终点对齐常规时段最新价，可能未收盘。
- 报价时间以美东时间显示，并与本地请求时间区分；来源链接、延迟说明和旧缓存标记可见。
- 真实新闻读取五家公司对应的 Yahoo Finance RSS，按 GUID 合并重复项，保留原标题、发布时间、域名及原文链接。代码标签仅表示检索匹配，不代表已确认的事件归属。
- 公司搜索、关注列表和右侧详情；模拟模式保留原有公告筛选。
- 交易计划：价格、风险预算、整股仓位、现金及单股上限；扣除已有同股持仓。
- 本地计划保存、归档、JSON 导出；兼容旧版 `trace-demo-v1` 数据。真实模式计划额外保存报价来源、时间、价格及示例账户估值；旧计划标记为原模拟计划。
- 真实模式默认带入行情价格，失效价必须由用户填写。报价不完整、失败或旧缓存状态不生成新计划。
- 示例持仓数量、成本、现金保持不变，按真实报价估值；净值等于现金加股票市值，压力测试使用同一组价格。
- A/B 收益对比及虚构净值曲线展示。
- 桌面与移动端布局、键盘导航、原生可关闭对话框。

## 数据边界

真实模式的行情与新闻来自 Yahoo Finance 的公开接口，可能延迟，也可能限流或变更；不保证交易所级实时性、服务可用性或历史时点数据质量。当前仅用于本地研究试用。日线采用上游 `close` 字段，不是包含分红的总回报序列，不能直接当作严谨回测数据。

真实模式不显示原先虚构的公司公告或指引，财报指引与一致预期标记为未接入。RSS 是新闻标题与链接，不等于 SEC 原始公告。没有调用 AI、券商或 LEAN。持仓数量、买入成本、现金与回测曲线仍是演示样本；计划不是订单，多个未执行计划不会预占现金或仓位。

服务只监听 `127.0.0.1`，通过固定白名单接口读取公开数据，不保存密钥或账户信息。缓存只在内存中：行情 60 秒、新闻 300 秒，点击刷新在缓存有效期内会复用结果；失败重试间隔 30 秒。有缓存时标记过期并保留原报价时间，无缓存时显示不可用，不自动回退到模拟价格。刷新页面或点击刷新才发起请求，不后台自动轮询。

仓位计算为做多整股示例。失效价不是保证成交的止损价，不包含费用与跳空。记录存于当前浏览器的 `trace-demo-v1`，清理浏览器数据会删除记录；可导出 JSON 留存。

## 文件

- `index.html`：页面入口。
- `styles.css`：响应式视觉样式，无外部字体或资源依赖。
- `app.js`：演示数据与交互。
- `server.py`：同源静态服务及 `/api/market`、`/api/news`、`/api/health`，并发读取、缓存与失败状态。
- `market.js`：真实数据加载、模式切换与失败处理。
- `market-demo.js`：固定模拟价格序列，只在显式选择模拟模式时显示。
- `logic.js`：独立的数字计算。
- Node 测试：`node --test demo/logic.test.cjs demo/market.test.cjs demo/live-market.test.cjs`。
- Python 测试：`python -m unittest discover -s demo -p test_server.py -v`。

原有地址 `#overview`、`#evidence`、`#plans`、`#portfolio`、`#experiments` 保持可用。

数据源：[Yahoo Finance](https://finance.yahoo.com/)、[行情来源及延迟说明](https://help.yahoo.com/kb/finance-for-web/SLN2310.html)。
